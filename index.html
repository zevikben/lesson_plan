העברה למכשיר אחר

הכינו במכשיר אחד וצפו במכשיר אחר
Google Drive
מעלה ל-Drive מה שחדש במכשיר, ומוריד מה שחדש ב-Drive. לא מוחק כלום במכשיר. כל שיעור נשמר כקובץ בשם השיעור, וכל שיר כקובץ בשם השיר. כדאי ללחוץ אחרי עריכה במכשיר אחד, ושוב לפני שפותחים במכשיר אחר.
הגדרות Drive
חיבור חד-פעמי: ב-console.cloud.google.com יוצרים פרויקט, מפעילים Google Drive API, מגדירים את מסך ההסכמה (מוסיפים את החשבון שלך כ-Test user) ויוצרים OAuth client ID מסוג Web application. ב-Authorized JavaScript origins מוסיפים את כתובת האפליקציה, למשל https://yourname.github.io (בלי נתיב). את ה-Client ID מדביקים כאן.
מתקדם: העברה בקובץ (בלי Drive)
ייצוא שומר הכול — שיעורים, שירים והגדרות — בקובץ אחד. ייבוא טוען קובץ כזה ומחליף את כל מה שקיים במכשיר. מתאים כגיבוי חירום או להעברה כשאין Drive.
